- **코드, 명령어, 파일 경로, 식별자는 번역하지 않습니다** — 그대로 실행·검색 가능해야 하기 때문입니다.
- 기술 용어는 처음 나올 때 원어를 병기합니다 (예: 점질량(located point mass)).
- 수치, 표, 링크 구조는 원본과 1:1로 대응됩니다.
- 문서 간 링크는 이 폴더 안에서 서로 연결되도록 조정했고, 원본 문서로 나가는 링크는 상대 경로로 유지했습니다.
